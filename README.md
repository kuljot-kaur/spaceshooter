# Space Shooter — Galaxy Invaders (Swing)

Simple Java Swing space shooter.

Controls:
- Left / Right arrows: Move
- Space: Shoot
- P: Pause / Resume
- R: Restart (after game over)

Run in VS Code:
1. Open this folder in VS Code.
2. Install Java Extension Pack.
3. Run `com.arcade.space.Main` (use Run button or .vscode launch config).
